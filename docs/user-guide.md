# 開発管理課タスク状況管理 — 操作手順書

**対象**: 初めてこのツールを使う方  
**URL**: https://dev-mgmt-task-board.vercel.app

---

## 画面の構成

```
┌──────────────────────────────────────────────────────────────────────┐
│ ヘッダー: タイトル・ビュー切替・サマリ統計                           │
├────────────┬──────────────────────┬────────────────────┬────────────┤
│            │                      │                    │            │
│ Pane 1     │ Pane 2               │ Pane 3             │ Pane 4     │
│            │                      │                    │            │
│ 年度目標   │ タスク一覧           │ タスク詳細         │ 備考メモ  │
│ の選択     │ （ステータス別）     │ （状況・次の一手） │ （折りたたみ）│
│            │                      │                    │            │
└────────────┴──────────────────────┴────────────────────┴────────────┘
```

| エリア | 役割 |
|--------|------|
| Pane 1（左サイドバー） | 年度目標または課員を選択する |
| Pane 2（タスク一覧） | ステータス別のタスク一覧。ここでタスクを追加・選択する |
| Pane 3（タスク詳細） | 選択中のタスクの詳細を入力・確認する |
| Pane 4（備考） | 経緯や状況のメモを時系列で残す |

## 基本操作

### ① 年度目標を選ぶ

1. 左サイドバー（Pane 1）から担当する年度目標をクリック
2. Pane 2 にその目標のタスク一覧が表示される

### ② タスクを追加する

1. Pane 2 で追加したいステータス（未着手・進行中 など）の右端にある **「＋」ボタン** をクリック
2. ダイアログが開くのでタスク名を入力して「追加」を押す
3. タスクが一覧に追加される

```
未着手  [2]                    ← ステータスグループ
  ┌──────────────────────┐  [＋]  ← ここをクリックしてタスク追加
  │ コードレビュー基準整備 │
  └──────────────────────┘
```

### ③ タスクの詳細を入力する

1. Pane 2 のタスクをクリックすると Pane 3 に詳細が表示される
2. 以下の項目を入力する

| 項目 | 内容 | 保存タイミング |
|------|------|---------------|
| タスク名 | タスクの名前（編集可） | 入力欄から離れると自動保存 |
| 担当者 | プルダウンから選ぶ（自分の名前を選択） | 選んだ瞬間に自動保存 |
| 開始期日 | 作業を始めた日 | 入力欄から離れると自動保存 |
| 終了期日 | 完了予定日 | 入力欄から離れると自動保存 |
| ステータス | 未着手 / 進行中 / 保留 / 完了 | 選んだ瞬間に自動保存 |
| 状況詳細 | いまの進捗を記述（下記参照） | 入力欄から離れると自動保存 |
| 課題 | 困っていることがあれば記述 | 入力欄から離れると自動保存 |
| 次の一手 | 次に取る行動を一文で | 入力欄から離れると自動保存 |

> **保存ボタンはありません。** 入力欄から離れた瞬間（クリックアウト）に自動でデータベースに保存されます。

## 各フィールドの書き方

### 状況詳細（必須）

「いま、どういう状態か」を事実ベースで記述します。

```
良い例:
  ドラフト第一版を作成済み。チームレビュー待ち。
  〇〇さんと調整中。今週中に方針を確定する予定。
  先週キックオフ実施。要件定義フェーズに入った。

避けたい例:
  対応中（状況が分からない）
  検討します（何を検討するのか不明）
```

### 課題（任意）

進めるうえで困っていること、障壁があれば記述します。

```
例:
  関係部署の承認が下りず着手できない。
  必要なツールのライセンスが未取得。
  前提となる〇〇が未完了のためブロックされている。
```

### 次の一手（必須）

「次に自分が取る具体的なアクション」を一文で書きます。

```
良い例:
  〇〇さんにレビュー依頼のメールを送る（今日中）
  火曜日の定例で承認を得る
  ライセンス申請書を総務に提出する

避けたい例:
  引き続き対応する（具体性がない）
  検討する（何をいつするのか不明）
```

## 備考（Pane 4）の使い方

備考は「経緯・状況を時系列で残すメモ欄」です。

### 開き方

Pane 3 の右端にある **「›」ボタン** をクリックすると備考が開きます。

### メモの追加

1. 「行を追加」ボタンをクリック
2. 今日の日付が自動入力される
3. 日付の後に状況をメモする

```
例:
  2026-07-01 キックオフ実施。参加者5名。
  2026-07-08 要件定義ドラフト完成。レビュー依頼済み。
  2026-07-15 レビューフィードバックを反映。承認待ち。
```

> **「次の一手」はここには書かない。** 次の行動は Pane 3 の「次の一手」欄に書いてください。備考は過去の記録用です。

## ステータスの変更

ステータスは2つの方法で変更できます。

**方法 A: Pane 3 のプルダウンで変更**
- タスクを選択 → Pane 3 の「ステータス」プルダウンで選ぶ

**方法 B: ドラッグ&ドロップ**
- Pane 2 でタスクをつかんで別のステータスグループにドロップ

## よくある操作

### タスクの担当者を自分に設定する
1. タスクをクリックして Pane 3 を開く
2. 「担当者」のプルダウンから自分の名前を選ぶ
3. 選んだ瞬間に自動保存される

### 完了したタスクを処理する
- ステータスを「完了」に変更するだけでOK
- しばらくは完了済みとして一覧に残ります
- 邪魔になったら右クリックメニューから「アーカイブ」で非表示にできます

### 課員ビューに切り替える
- ヘッダーの「課員ビュー」タブをクリック
- 左サイドバーに課員一覧が表示される
- 課員名をクリックするとその人のタスクを全テーマ横断で確認できる

## 困ったときは

| 症状 | 対処 |
|------|------|
| 入力したのに消えた | ページをリロードして確認。もう一度入力して入力欄の外をクリック |
| タスクが表示されない | 左サイドバーで正しい年度目標が選ばれているか確認 |
| 担当者欄に自分の名前がない | 課長に連絡してメンバー一覧への追加を依頼 |
