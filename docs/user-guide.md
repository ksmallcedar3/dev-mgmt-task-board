# 開発管理課タスク状況管理 — 操作手順書

**対象**: 初めてこのツールを使う方  
**URL**: https://dev-mgmt-task-board.vercel.app

---

## 画面の構成

```
┌──────────────────────────────────────────────────────────────────────┐
│ ヘッダー: タイトル・ビュー切替（目標ビュー / 課員ビュー）           │
├────────────┬──────────────────────┬────────────────────┬────────────┤
│            │                      │                    │            │
│ ① 年度目標 │ ② タスク一覧         │ ③ タスク詳細       │ ④ 備考メモ │
│            │                      │                    │            │
│ の選択     │ （中項目グループ別） │ （状況・次の一手） │ （時系列） │
│ （左側）   │                      │                    │            │
│            │                      │                    │            │
└────────────┴──────────────────────┴────────────────────┴────────────┘
```

| エリア | 役割 |
|--------|------|
| ① 年度目標欄（左サイドバー） | 年度目標または課員を選択する |
| ② タスク一覧 | 中項目グループ別のタスク一覧。タスクの追加・選択をする |
| ③ タスク詳細 | 選択中のタスクの詳細を入力・確認する |
| ④ 備考メモ | 経緯や状況のメモを時系列で残す |

## 中項目とは

タスクには「**中項目**」というグループ分けラベルを付けられます。  
② タスク一覧では、中項目ごとにタスクが折りたたまれて表示されます。

```
年度目標「人財育成計画」
    │
    ├── 資格取得支援制度      ← 中項目あり
    │   ├── 研修A
    │   └── 研修B
    │
    └── （未分類）            ← 中項目を設定していないタスクの置き場
        └── 説明会準備
```

中項目は**タスクごとに自由テキストで設定**します。専用のマスタ一覧はなく、  
同じ文字列のタスクが自動でグループにまとめられます。

## 基本操作

### ① 年度目標を選ぶ

1. 左サイドバー（① 年度目標欄）から担当する年度目標をクリック
2. ② タスク一覧に、その目標のタスクが中項目グループ別で表示される

### ② タスクを追加する

**方法 A — ヘッダーの「＋」ボタン（中項目を自分で指定する）**

1. ② タスク一覧のヘッダー右端にある **「＋」ボタン** をクリック
2. ダイアログが開く
3. 「中項目」に分類名を入力（空欄のままなら「（未分類）」に入る）
4. 「タスク名」を入力して「追加」を押す

```
人財育成計画                   [＋]  ← ヘッダーの ＋
┌────────────────────────────────┐
│ ∨ 資格取得支援制度  ●2  [＋]  │  ← グループごとの ＋
│   タスクA                      │
│   タスクB                      │
└────────────────────────────────┘
```

**方法 B — グループ行の「＋」ボタン（中項目が自動セットされる）**

1. 追加したい中項目グループの右端にある **「＋」ボタン** をクリック
2. ダイアログが開き、その中項目が **自動でセット済み** の状態になる
3. 「タスク名」を入力して「追加」を押す

> **追加したタスクのステータスは「未着手」固定です。** あとから ③ タスク詳細で変更できます。

### ③ タスクの詳細を入力する

1. ② タスク一覧のタスクをクリックすると、③ タスク詳細に内容が表示される
2. 以下の項目を入力する

| 項目 | 内容 | 保存タイミング |
|------|------|---------------|
| タスク名 | タスクの名前（編集可） | 入力欄から離れると自動保存 |
| 中項目 | 所属グループ名（変更するとグループが移動） | 入力欄から離れると自動保存 |
| 担当者 | プルダウンから選ぶ | 選んだ瞬間に自動保存 |
| 開始期日 | 作業を始めた日 | 入力欄から離れると自動保存 |
| 終了期日 | 完了予定日 | 入力欄から離れると自動保存 |
| ステータス | 未着手 / 進行中 / 保留 / 完了 | 選んだ瞬間に自動保存 |
| 状況詳細 | いまの進捗を記述 | 入力欄から離れると自動保存 |
| 課題 | 困っていることがあれば記述 | 入力欄から離れると自動保存 |
| 次の一手 | 次に取る行動を一文で | 入力欄から離れると自動保存 |

> **保存ボタンはありません。** 入力欄から離れた瞬間に自動でデータベースに保存されます。

## 各フィールドの書き方

### 状況詳細（必須）

「いま、どういう状態か」を事実ベースで記述します。

```
良い例:
  ドラフト第一版を作成済み。チームレビュー待ち。
  〇〇さんと調整中。今週中に方針を確定する予定。
  先週キックオフ実施。要件定義フェーズに入った。

避けたい例:
  対応中（状況が分からない）
  検討します（何を検討するのか不明）
```

### 課題（任意）

進めるうえで困っていること、障壁があれば記述します。

```
例:
  関係部署の承認が下りず着手できない。
  必要なツールのライセンスが未取得。
  前提となる〇〇が未完了のためブロックされている。
```

### 次の一手（必須）

「次に自分が取る具体的なアクション」を一文で書きます。

```
良い例:
  〇〇さんにレビュー依頼のメールを送る（今日中）
  火曜日の定例で承認を得る
  ライセンス申請書を総務に提出する

避けたい例:
  引き続き対応する（具体性がない）
  検討する（何をいつするのか不明）
```

## 備考（④ 備考メモ）の使い方

備考は「経緯・状況を時系列で残すメモ欄」です。

### 開き方

③ タスク詳細の右端にある **「›」ボタン** をクリックすると、④ 備考メモが開きます。

### メモの追加

1. 「行を追加」ボタンをクリック
2. 今日の日付が自動入力される
3. 日付の後に状況をメモする

```
例:
  2026-07-01 キックオフ実施。参加者5名。
  2026-07-08 要件定義ドラフト完成。レビュー依頼済み。
  2026-07-15 レビューフィードバックを反映。承認待ち。
```

> **「次の一手」はここには書かない。** 次の行動は ③ タスク詳細の「次の一手」欄に書いてください。④ 備考メモは過去の記録用です。

## ステータスの変更

ステータスは 2 つの方法で変更できます。

**方法 A: ③ タスク詳細のプルダウンで変更**
- タスクを選択 → ③ タスク詳細の「ステータス」プルダウンで選ぶ

**方法 B: ドラッグ＆ドロップ（フィルター表示時のみ）**
- ② タスク一覧上部のメンバー名などでフィルターをかけるとステータスグループ表示に切り替わる
- タスクをつかんで別のステータスグループにドロップする

## タスクのアーカイブ

「完了済みで一覧から消したい」「誤って追加した」などのタスクはアーカイブできます。  
アーカイブはデータを削除するのではなく、**一覧から隠す**操作です。復元可能です。

### アーカイブする

1. タスク行にカーソルを乗せる
2. 右上に **「📦」ボタン** が現れる
3. クリックすると確認ダイアログが開く
4. 「アーカイブ」を押す → タスクが「アーカイブ済み」セクションに移動

### 復元する

1. ② タスク一覧の下部にある「アーカイブ済み」セクションを開く
2. タスク行にカーソルを乗せる
3. **「↩ 復元」ボタン** をクリック

## よくある操作

### 中項目を変更・設定する
1. タスクをクリックして ③ タスク詳細を開く
2. 「中項目」フィールドに分類名を入力（既存の中項目は補完候補として表示される）
3. 入力欄から離れると自動保存され、② タスク一覧のグループが更新される

### 課員ビューに切り替える
- ヘッダーの「課員ビュー」タブをクリック
- 左サイドバーに課員一覧が表示される
- 課員名をクリックするとその人のタスクを全テーマ横断で確認できる

### 担当者を未割当のままにしない
- 担当者が未設定のタスクには「未割当」バッジが赤字で表示される
- タスクをクリックして ③ タスク詳細の「担当者」プルダウンから名前を選ぶ

## 困ったときは

| 症状 | 対処 |
|------|------|
| 入力したのに消えた | ページをリロードして確認。再入力後、入力欄の外をクリックして保存する |
| タスクが表示されない | 左サイドバーで正しい年度目標が選ばれているか確認する |
| 担当者欄に自分の名前がない | 課長に連絡してメンバー一覧への追加を依頼する |
| ＋ボタンが見当たらない | 目標ビュー（左サイドバーで年度目標を選択した状態）になっているか確認する |
| アーカイブしたタスクを元に戻したい | ② タスク一覧下部の「アーカイブ済み」を開いて復元ボタンを押す |
| 画面が真っ白 / エラー表示 | ページをリロード。改善しない場合は課長に連絡する |
