# Hooks

このプロジェクトのフックはユーザーレベル（`~/.cursor/hooks.json`）で管理しています。

## SKILL.md 自動レビュー

`SKILL.md` を Write するたびに read-only のプロンプトフックが発火し、
レビュー結果を `additional_context` として本体 AI に返します。

- **レビュアー**: prompt hook（読み取り専用、ファイル変更不可）
- **修正**: 本体 AI が担当
- **設定ファイル**: `~/.cursor/hooks.json`

### レビュー観点

| 観点 | 内容 |
|------|------|
| SSoT 原則 | 参照ドキュメントを見ればわかる内容が本文に含まれていないか |
| 簡潔さ | 暗黙的であるべき手順が逐一書かれていないか |
| トリガー条件 | いつ発動するかが明確か |
| 再利用性 | 特定タスクに限定されすぎていないか |
